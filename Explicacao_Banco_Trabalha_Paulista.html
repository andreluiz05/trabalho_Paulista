Estrutura e Dados do Trabalha Paulista

Contexto Geral: Este banco de dados foi projetado para sustentar o ecossistema do Trabalha Paulista, conectando cidadãos a oportunidades de emprego, cursos de capacitação e permitindo que autônomos locais (MEIs) ofereçam seus serviços.

1. Usuários Principais (Tabela usuarios)

Foram criados 3 usuários para demonstrar os diferentes perfis da aplicação. Todos possuem a senha 123456 (salva de forma segura usando criptografia BCrypt).

  • Maria Silva (maria@email.com) - Perfil: candidato. Representa a cidadã comum buscando emprego e qualificação técnica.
  • João Souza (joao@email.com) - Perfil: empreendedor. Representa o microempreendedor local que busca divulgar serviços e fazer mentorias para crescer seu negócio.
  • Administrador (admin@trabalhapaulista.com) - Perfil: ADMIN. Representa a prefeitura/gestor, responsável por cadastrar as vagas oficiais e firmar parcerias institucionais.

2. Oportunidades Oficiais do Município

Dados inseridos pela administração pública:

  • Vagas (vagas): Foi cadastrada uma vaga de Desenvolvedor Java Jr (CLT) na TechCorp e uma vaga de Estagiário de TI na HelpDesk IT.
  • Parcerias (parcerias): A prefeitura fechou uma parceria estratégica com a empresa TechCorp para contratação exclusiva de alunos do portal.

O foco na educação profissionalizante:

4. Serviços da Comunidade (servicos)

Os próprios usuários podem empreender na plataforma:
